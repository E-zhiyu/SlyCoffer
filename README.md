# 斯莱账本

> 一款Material You风格的极简的个人记账工具，功能干净纯粹，不收集任何用户数据，为您提供清爽的记账体验。

## ✨特性一览

| 特性         | 说明                                                                                           |
|--------------|------------------------------------------------------------------------------------------------|
| **记账查账** | 记录您日常生活中的交易信息，支持自定义备注和标签以及添加图片，支持通过备注和标签搜索流水记录。 |
| **自动记账** | 通过通知监听和无障碍服务实现自动记账，支持自定义记账规则。                                     |
| **预算管理** | 支持添加若干预算，通过标签自动更新余额，余额较低时发送通知提醒。                               |
| **报表统计** | 根据某一时间段的流水记录生成收支和结余等数据，且能够根据标签或月份对流水记录进行分类。         |
| **债务管理** | 支持查看借还记录，并根据借还记录自动计算还款金额。                                             |
| **数据管理** | 支持将数据导出为压缩包以及从压缩包中导入数据，可实现记账规则的分享和数据备份等功能。           |
| **隐私保护** | 开启隐私保护功能后，每次进入APP都需要通过屏锁进行身份验证。此功能需要设置锁屏验证方式。        |

## 🛡️需要用到的权限

| 权限名称                 | 说明                                                          |
|--------------------------|---------------------------------------------------------------|
| **摄像头权限**           | 允许APP使用摄像头拍照。                                       |
| **应用列表权限**         | 允许APP获取设备上已安装的应用信息。                           |
| **通知权限**             | 允许APP发送通知。                                             |
| **通知监听权限**         | 允许APP获取发送通知的应用以及通知内容，用于实现自动记账。     |
| **自启动权限**           | 定制安卓系统特有的权限，允许后APP能在后台自动启动并运行任务。 |
| **“无限制”电池优化策略** | 降低APP被杀后台的几率，确保APP能在后台运行自动化服务。        |
| **精确闹钟权限**         | 允许APP精确地在特定时刻执行任务。                             |
| **系统启动监听权限**     | 该权限无需手动授予，用于在系统启动后唤醒APP并安排后台任务。   |
| **位置权限**             | 允许APP获取当前地理位置。                                     |

## 🎗️使用建议

- APP支持Android 9及以上的设备，推荐使用不低于Android 12的设备以获得最佳的使用体验。
- 部分国产系统即便授予通知权限也无法弹出横幅通知，需要手动进入通知设置并允许发送横幅通知。
- 若使用的是定制安卓系统（如HyperOS、ColorOS等），请授予自启动权限以确保软件能够自启动，否则部分自动化功能会失效。
